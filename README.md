# Portfolio Website

Personal portfolio site for Jair Andres Lagos Pereira, built with plain HTML5, CSS3 and vanilla JavaScript (no frameworks, no build step).

## Features

- Responsive single-page layout (About, Skills, Experience, Contact)
- - CSS custom properties for a consistent color theme
  - - Simple client-side form validation and submit handling in JavaScript
   
    - ## Tech stack
   
    - - HTML5
      - - CSS3 (Flexbox, custom properties)
        - - Vanilla JavaScript (DOM events)
         
          - ## Run locally
         
          - Clone the repo and open `index.html` in your browser. No build tools or dependencies required.
         
          - ```
            git clone https://github.com/jair10crack/portfolio-website.git
            cd portfolio-website
            open index.html
            ```
